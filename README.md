# Ks-darsi

Codial: Kompyuter savodxonligi + AI kursi (12 dars) slaydlari.

Bitta `index.html` fayl: brauzerda oching, o'rnatish shart emas.

## Boshqarish

- `←` `→`, `PageUp` `PageDown`, `Probel`: slaydlar orasida yurish
- `Home` / `End`: dars boshi / oxiri
- `F`: to'liq ekran
- Telefon va planshetda: slaydni chapga yoki o'ngga surish
- Manzil satrida dars va slayd saqlanadi, masalan `#dars-4/7`
- "Izohlarni yashirish" tugmasi o'qituvchi izohlarini proyektorda yashiradi
