# Ks-darsi

Codial: Kompyuter savodxonligi + AI kursi (12 dars) slaydlari.

Bitta `index.html` fayl: brauzerda oching, o'rnatish shart emas.

## Codial reklamasi

Har sahifada Codial belgilari bor: logo, har slayd tagida almashib turadigan qisqa xabar va telefon raqami, har dars oxirida shu mavzu davomi bo'lgan kursni tanishtiruvchi slayd, bosh sahifada "Codial haqida" bo'limi. Ma'lumotlar va logo [codialinfo.uz](https://www.codialinfo.uz/) saytidan olingan. Matnlar `index.html` ichida `CO`, `COURSES`, `PERKS`, `LP` va `STRIP` o'zgaruvchilarida turadi, logo va ikonka `img/` papkasida.

## Boshqarish

- `←` `→`, `PageUp` `PageDown`, `Probel`: slaydlar orasida yurish
- `Home` / `End`: dars boshi / oxiri
- `F`: to'liq ekran
- Telefon va planshetda: slaydni chapga yoki o'ngga surish
- Manzil satrida dars va slayd saqlanadi, masalan `#dars-4/7`
- "Izohlarni yashirish" tugmasi o'qituvchi izohlarini proyektorda yashiradi
